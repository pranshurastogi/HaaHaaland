# Decisions

1. **Free core never hard-depends on partners.** Missing Linkup/LLM/Hermes/audio produces a labelled low-confidence fallback.
2. **Curated taxonomy over invented player lore.** Twenty-four safe archetypes are version controlled.
3. **Original visual language.** Warm editorial scouting report; no official marks, photographs, or Ultimate Team imitation.
4. **No auth dashboard.** Email save is the only P0 identity step.
5. **Private Hermes boundary.** VAR is P1, feature-flagged, and accepts only narrow validated context.
6. **No decorative payments.** Dodo remains disabled until a live checkout and webhook can be tested.
7. **Local state is explicitly non-production.** Convex is the durability gate for launch.
