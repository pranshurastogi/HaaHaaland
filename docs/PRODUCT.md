# Product

## Promise

HaaHaaLand creates a recognizable, confidence-aware football identity card from public evidence in under 60 seconds. The experience is useful before signup and every result is an acquisition surface.

## Core journey

Landing → normalized X handle → public research/manual evidence → curated archetype → validated card → result view → PNG/share/challenge → optional email save.

Activation is recorded only when generation completes, the result is viewed, and either an email is saved or a challenge is created. Refreshes, failures, and test traffic are not activation.

## Scope status

The local P0 core loop, fallback states, card download, email save, challenge link, and share actions are implemented. Production partner calls require owner credentials. P1 Hermes VAR, ElevenLabs audio, and P2 payments remain feature-flagged/off until the free production loop is verified.
